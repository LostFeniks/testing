# Credit Card Validator

[![CI/CD](https://github.com/LostFeniks/testing/actions/workflows/ci.yml/badge.svg)](https://github.com/LostFeniks/testing/actions/workflows/ci.yml)
[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live-brightgreen)](https://LostFeniks.github.io/testing/)

## 🎯 Описание

Виджет для валидации номеров банковских карт с определением платежной системы (Visa, Mastercard, American Express, Discover, МИР).

## 🚀 Демо

[Посмотреть демо](https://LostFeniks.github.io/testing/)

## ✨ Особенности

- ✅ Валидация номера карты по алгоритму Луна
- 🎯 Автоматическое определение платежной системы
- 🎨 Визуальная индикация активной платежной системы
- ✅ Валидация в реальном времени
- 📱 Адаптивный дизайн
- 🧪 Полное покрытие тестами (unit + e2e)

## 🛠️ Технологии

- **Frontend:** JavaScript (ES6+), CSS3, HTML5
- **Сборка:** Webpack 5
- **Тестирование:** Jest (unit) + Puppeteer (e2e)
- **CI/CD:** GitHub Actions
- **Хостинг:** GitHub Pages
